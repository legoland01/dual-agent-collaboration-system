# Bug 报告：Agent 流程合规性不足

**Bug 编号**: BUG-20260205-001
**严重程度**: P1
**发现日期**: 2026-02-05
**发现人**: 人类专家
**状态**: 待修复

---

## 问题描述

Agent 反复需要人类提醒才能回到 oc-collab 规范流程，无法自主维持正确的流程状态。

## 问题表现

| 场景 | 问题表现 |
|------|----------|
| 文档状态管理 | 需要人类提醒解除 DRAFT 状态才能进入评审 |
| 流程阶段判断 | 需要人类提醒"下一步应该是设计阶段而非开发阶段" |
| 上下文保持 | 频繁丢失对 oc-collab 流程规范的记忆 |

## 复现步骤

1. Agent 完成需求文档评审后，人类未明确指示下一步
2. Agent 直接建议"进入开发阶段"
3. 人类提醒："下一步不应该是设计文档吗？"
4. Agent 纠正，进入设计流程

## 根本原因分析

| 可能原因 | 说明 |
|----------|------|
| 上下文丢失 | 流程规范未持久化到长期记忆，导致上下文旋转 |
| 主动推理不足 | 未能基于当前状态主动推导出规范流程 |
| 过度依赖外部提醒 | 缺乏自我监控机制，过度依赖人类干预 |

## 影响范围

- oc-collab 流程执行依赖人工监督
- Agent 自主性不足，无法独立推进项目
- 增加人类认知负担

## 建议修复方案

### 方案 1：会话状态持久化

在会话开始时加载 oc-collab 流程规范，并在整个会话期间保持活跃状态。

### 方案 2：流程合规检查机制

在每个关键决策点，自动检查当前状态与规范流程的一致性。

### 方案 3：主动流程提醒

Agent 主动监控流程状态，在需要时主动提示当前应该执行的操作。
