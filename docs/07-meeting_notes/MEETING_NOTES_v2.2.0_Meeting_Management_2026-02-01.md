## 1. 会议管理功能需求

### 1.1 会议类型

| 类型 | 说明 |
|------|------|
| Agent 间讨论 | Agent 1 ↔ Agent 2 ↔ 其他 Agent 的讨论 |
| 产品经理与客户讨论 | 需要导入外部会议信息 |

### 1.2 外部会议导入

| 导入内容 | 说明 |
|----------|------|
| 录音文件 | .mp3, .wav 等 |
| 录音转写文字 | 语音转文字结果 |
| 会议纪要 | 人工整理的纪要 |

### 1.3 版本关联

| 需求 | 说明 |
|------|------|
| 会议关联版本 | 每个会议只关联特定版本 (v2.1.0, v2.2.0) |
| 版本隔离 | 防止不同版本的内容互相污染 |
| 版本追溯 | 可以追溯某版本的所有相关会议 |

---

## 2. 核心决策

### 2.1 会议纪要生成

| 场景 | 生成方式 |
|------|----------|
| Agent 间讨论 | Agent 自动生成纪要 |
| 上传录音/转写 | Agent 自动生成纪要 |

### 2.2 版本关联与需求修改

- Agent 根据会议内容**自动判断**关联版本
- Agent 根据会议结论**自主决定**是否修改需求文档

### 2.3 会议结构

| 字段 | 说明 |
|------|------|
| 会议编号 | MTG-001, MTG-002... |
| 会议主题 | 简述讨论主题 |
| 参与者 | 谁参与了会议 |
| 关联版本 | 关联的版本号 |
| 关键决策 | 会议上做出的决策 |
| 待办事项 | 会议产生的待办 |
| 附件 | 录音、转写等文件 |
