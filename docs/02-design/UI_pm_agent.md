## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 简洁优先 | 减少用户记忆负担 |
| 单一入口 | 所有操作从一个入口进入 |
| 渐进式 | 复杂功能分层展示 |
| 响应式 | 适配桌面端为主 |

## 2. 页面架构

### 2.1 整体布局

```
┌─────────────────────────────────────────────────────────────────┐
│  ┌──────────┐  ┌─────────────────────────────────────────────┐  │
│  │          │  │                                              │  │

│  │  - 首页   │  │  (根据导航显示对应内容)                    │  │

│  │  - 进度   │  │                                              │  │
│  │  - 问题   │  │                                              │  │
│  │  - 设置   │  │                                              │  │
```

### 2.2 导航结构

| 页面 | 路由 | 说明 |
|------|------|------|
| 首页/信息输入 | `/` | 客户材料唯一入口 |
| 项目列表 | `/projects` | 项目管理 |
| 客户管理 | `/customers` | 客户配置 |
| 进度总览 | `/dashboard` | 进度可视化 |

## 3. 页面设计

### 3.1 首页 - 信息输入页

**路由**: `/`
**功能**: 客户材料唯一入口，显示处理结果，自动化处理

```
┌─────────────────────────────────────────────────────────────────┐
│  📥 信息输入                                                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌───────────────────────────────────────────────────────┐    │
│  │  [拖拽文件到此处，或点击上传]                           │    │
│  │                                                       │    │
│  │     支持：图片 / 音频 / 文档 / 日志                   │    │
│  │                                                       │    │
│  │  预处理状态：                                          │    │
│  │  ├─ 图片 → OCR提取文字                               │    │
│  │  ├─ 音频 → 转录为文字                                │    │
│  │  ├─ PDF → 提取文本                                  │    │
│  │  └─ 文档 → 解析内容                                  │    │
│  └───────────────────────────────────────────────────────┘    │
│                                                                 │
│  ───────────────────────────────────────────────────────────    │
│                                                                 │
│  手动输入：                                                     │
│  ┌───────────────────────────────────────────────────────┐    │
│  │  [在这里输入项目相关信息...]                           │    │
│  └───────────────────────────────────────────────────────┘    │
│                                                                 │
│  ───────────────────────────────────────────────────────────    │
│                                                                 │
│  🤖 自动化流程预览：                                            │
│  ┌───────────────────────────────────────────────────────┐    │
│  │  输入 → 预处理 → 理解 → 分类 → [BUG/需求] → 跟踪   │    │
│  └───────────────────────────────────────────────────────┘    │
│                                                                 │
│  ───────────────────────────────────────────────────────────    │
│                                                                 │
│  📋 处理结果列表：                                              │
│  ┌───────────────────────────────────────────────────────┐    │
│  │ 文件        │ 类型   │ 项目    │ 反馈编号    │ 状态   │   │
│  ├───────────────────────────────────────────────────────┤    │
│  │ 截图1.png  │ [BUG]  │ 项目A  │ BUG-20260217-001 │ 已处理 │   │
│  │   └ OCR提取: "系统登录报错"                          │   │
│  ├───────────────────────────────────────────────────────┤    │
│  │ 语音1.m4a  │ [需求] │ 项目B  │ REQ-20260217-001  │ 已处理 │   │
│  │   └ 转录: "希望增加批量导出功能"                     │   │
│  ├───────────────────────────────────────────────────────┤    │
│  │ 需求.docx   │ [需求] │ 项目A  │ REQ-20260217-002  │ 已处理 │   │
│  │   └ 提取: "用户权限管理模块"                          │   │
│  ├───────────────────────────────────────────────────────┤    │
│  │ 日志.log    │ [BUG]  │ 项目C  │ BUG-20260217-002  │ 处理中 │   │
│  └───────────────────────────────────────────────────────┘    │
│                                                                 │
│  ───────────────────────────────────────────────────────────    │
│                                                                 │
│  最近处理：                                                     │
│  ┌───────────────────────────────────────────────────────┐    │
│  │ [10:30] 客户A-项目X 登录BUG → [BUG] → BUG-001   │    │
│  │ [10:25] 客户B-项目Y 功能建议 → [需求] → REQ-001  │    │
│  └───────────────────────────────────────────────────────┘    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**预处理说明**:

| 文件类型 | 预处理步骤 | 说明 |
|----------|------------|------|
| 图片(PNG/JPG) | OCR提取文字 | 调用LLM Vision |
| 音频(M4A/WAV) | 转录为文字 | 调用Whisper |
| PDF | 提取文本 | 解析文本内容 |
| Word | 解析内容 | 提取富文本 |
| 日志 | 错误提取 | LLM分析异常 |

**处理结果字段**:

| 字段 | 说明 |
|------|------|
| 文件 | 上传的文件名 |
| 类型 | 自动识别：[BUG] / [需求] / [其他] |
| 项目 | 自动匹配的项目名 |
| 反馈编号 | BUG-XXXX 或 REQ-XXXX |
| 状态 | 处理中 / 已处理 / 需确认 |
