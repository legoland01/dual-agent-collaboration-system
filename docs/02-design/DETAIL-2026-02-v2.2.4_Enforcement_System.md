## 8. 数据流设计

### 8.1 Git提交流程

```
Agent
  ↓
oc-collab git commit --force
  ↓
GitCommit.validate_workspace() → SignoffEnforcer.check_signoff_status()
  ↓
通过 → git commit
拒绝 → 提示错误信息
```

### 8.2 阶段推进流程

```
Agent
  ↓
oc-collab phase advance <target_phase>
  ↓
PhaseAdvance.check_prerequisites()
  ↓
通过 → 更新 project_state.yaml
拒绝 → 提示不满足条件
```
