## 2. FR-OWNER-001 文件Owner机制

### 2.1 功能定位

```
协作规范层
    │
    └── 角色边界
            │
            ├── 现状：RoleBoundaryChecker（只对CLI生效）
            │
            └── 增强：文件Owner机制（覆盖Edit/Write/Bash）
```

### 2.2 功能结构

```
文件Owner机制
│
├── 文件创建者识别
│   └── 创建文件时记录Agent ID
│
├── 权限控制
│   ├── Owner：可修改
│   └── 非Owner：拒绝修改
│
└── Owner转移
    └── 签署后转移给签署方
```

### 2.3 与现有机制的关系

```
RoleBoundaryChecker（CLI）
    │
    ├── 覆盖：CLI命令
    │
    └── 增强：文件Owner机制
                │
                └── 覆盖：Edit/Write/Bash
```

## 6. FR-PROC-002 评审机制优化

### 6.1 功能定位

```
流程规范层
    │
    └── 评审流程
            │
            ├── 现状：两个评审并存（Technical + Critical）
            │
            └── 优化：明确优先级
```

### 6.2 功能结构

```
评审机制优化
│
├── 评审类型
│   ├── Technical Review：技术可行性
│   └── Critical Review：批判性质疑
│
├── 优先级规则
│   └── Critical Review > Technical Review
│
└── 最终决策
    └── 一个评审结论
```

### 6.3 评审优先级图

```
评审流程
    │
    ├── Technical Review
    │       │
    │       └── 输出：技术可行性评估
    │
    └── Critical Review
            │
            └── 输出：批判性结论
                    │
                    └── 覆盖：Technical Review结论
```
