### 2.1 3.6 EventListener - HTTP端口应可配置

**问题**: HTTP服务端口硬编码为8080

**原文**:
```python
def start_listening(port: int = 8080) -> None:
```

**建议**: 端口应从配置文件读取，支持环境变量覆盖

```python
def start_listening(port: Optional[int] = None) -> None:
    if port is None:
        port = self.config.get_webhook_port()  # 从配置文件读取
```
