## 8. 特别议题：关于意图分析模块的必要性

### 8.1 设计现状

设计文档中依赖dossierai的`/intent/recognize` API进行意图识别（BUG vs 功能需求）。

### 8.2 MiniMax 2.5模型能力分析

以MiniMax 2.5为代表的新一代LLM具备：
- ✅ 强大的文本理解和推理能力
- ✅ 上下文理解能力
- ✅ 零样本分类能力
- ✅ 多轮对话能力
- ✅ 结构化输出能力

### 8.3 评估结论

**结论：可以使用LLM直接替代专门的意图分析模块**

理由：
1. **能力充足**: MiniMax 2.5等现代LLM本身具备准确的文本分类能力，无需专门训练
2. **架构简化**: 减少一个外部服务依赖，提高系统稳定性
3. **成本优化**: 减少一次API调用，降低延迟和成本
4. **维护简化**: 统一使用一种LLM服务，减少维护成本

**建议修改**：
- 在InputHandler中直接调用LLM进行意图识别
- 不再依赖dossierai的`/intent/recognize` API
- ClassifierService可以直接使用LLMService进行分类
