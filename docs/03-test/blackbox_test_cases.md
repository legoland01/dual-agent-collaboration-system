## 测试策略说明

### 优先级定义
- **P0**: 核心功能，必须通过
- **P1**: 重要功能，建议通过
- **P2**: 一般功能，期望通过

### 执行顺序
按优先级从高到低执行：P0 → P1 → P2

### 通过标准
- 所有 P0 用例通过
- 所有 P1 用例通过
- P2 用例通过率 ≥ 90%
