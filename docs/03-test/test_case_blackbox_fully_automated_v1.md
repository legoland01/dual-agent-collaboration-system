# 双Agent全自动协作框架 - 黑盒测试用例

## 版本信息
- **版本**: v1
- **创建日期**: 2026-01-31
- **作者**: Agent 1 (产品经理+测试)
- **关联需求版本**: v2
- **测试类型**: 黑盒测试

## 1. 测试概述

### 1.1 测试目标
验证双Agent全自动协作框架的功能是否符合需求规格，包括：
- Agent自主行为是否符合预期
- Git状态检测是否准确
- 状态机转换是否正确
- 文档自动生成是否符合模板
- 全流程是否可正常执行

### 1.2 测试范围

| 测试对象 | 测试内容 | 优先级 |
|---------|---------|-------|
| Agent 1 | 需求编写、评审、黑盒测试、部署 | P0 |
| Agent 2 | 需求评审、设计、开发、白盒测试、Bug修复 | P0 |
| Git Monitor | 状态检测、触发信号识别 | P0 |
| Brain Engine | 状态机转换、行为规则匹配 | P0 |
| Doc Generator | 文档模板填充、格式转换 | P1 |
| 异常处理 | Git冲突、超时、权限问题 | P1 |

### 1.3 测试环境
- Python 3.8+
- Git 2.0+
- Gitee账户（两个Agent各自一个）
- GitHub账户（CI/CD）

### 1.4 测试数据准备

| 数据类型 | 准备内容 |
|---------|---------|
| 空项目 | 初始化state/project_state.yaml |
| 模板文件 | templates/目录下所有模板 |
| 测试账户 | 两个Gitee账户的token |
