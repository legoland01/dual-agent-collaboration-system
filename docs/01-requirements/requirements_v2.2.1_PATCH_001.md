## 2. 功能需求

### 2.1 流程合规检查机制

**需求编号**: FR-COMPLIANCE-001

**问题背景**:
Agent 在执行关键操作前，应自动检查当前状态是否符合 oc-collab 流程规范，而非依赖人类提醒。

**解决方案**:

#### 2.1.1 状态合规检查

**描述**: Agent 在执行操作前，自动检查前置条件。

**检查规则**:
```python
COMPLIANCE_RULES = {
    "draft_cannot_review": True,       # DRAFT 状态不能评审
    "draft_cannot_signoff": True,      # DRAFT 状态不能签署
    "review_requires_ready": True,      # 评审前必须 READY
    "phase_sequence_required": True,    # 必须按流程顺序执行
}
```

#### 2.1.2 主动流程推理

**描述**: Agent 能够根据当前状态主动推导出下一步应该执行的操作。

**推理逻辑**:
```
当前状态 → 查找 oc-collab 规范 → 推导出应该执行的操作 → 主动提示
```

**示例**:
```
当前状态: 需求文档 APPROVED
应该执行: 设计阶段
Agent 主动提示: "需求文档已签署，现在进入设计阶段吗？"
```

#### 2.1.3 流程规范持久化

**描述**: 在会话开始时加载 oc-collab 流程规范，并在整个会话期间保持活跃状态。

**实现方式**:
- 会话开始时自动加载 `skills/oc_collab_process_guide/`
- 流程规范作为系统提示的一部分长期保持
