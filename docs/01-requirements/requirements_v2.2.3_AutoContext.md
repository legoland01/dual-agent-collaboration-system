---

## 1. 问题背景

### 1.1 当前问题

| 场景 | 问题 |
|------|------|
| Session 重启 | AI 忘记所有协作规则 |
| Compaction | AI 上下文丢失，需要重新解释 oc-collab |
| 新项目 | AI 不知道什么是 oc-collab |

### 1.2 根本原因

```
现象：AI 在新 session 中忘记 oc-collab 规则
原因：OpenCode 不自动加载 ./skills/* 或 ./docs/*
结果：每次都要重新解释协作框架
```

### 1.3 影响

- 用户每次都要重复解释 oc-collab
- 新 AI 无法快速上手
- 协作效率低下

---

## 2. 解决方案

### 2.1 核心设计

```
Human: "你是 agent1。"
    ↓
AI 自动读取项目根目录的 ".a" 文件
    ↓
AI 了解 oc-collab 协作规则
```

### 2.2 约定

| 元素 | 约定 |
|------|------|
| 文件名 | `.a` |
| 文件位置 | 项目根目录 |
| 文件内容 | Agent 规则、角色定义、协作流程 |

### 2.3 用户操作

| 场景 | 用户输入 |
|------|----------|
| Agent 1 加入 | `你是 agent1。` |
| Agent 2 加入 | `你是 agent2。` |

**用户只需要记住这一句话**，AI 自动读取 `.a` 文件。

### 2.4 文件内容

```markdown
# OC-Collab 协作规则

## 角色

- **Agent 1 (产品经理)**:
  - 创建需求和设计文档
  - 主持评审和验收
  - 推进阶段流转

- **Agent 2 (开发)**:
  - 评审需求和设计
  - 实现代码和测试
  - 签署确认

## 流程

```
需求 → 设计 → 开发 → 测试 → 部署
  ↓      ↓      ↓      ↓      ↓
 签署    签署    签署    签署    完成
```

## 规则

1. 每个阶段需要双方签署
2. 使用 oc-collab CLI 命令管理项目
3. 文档存放在 docs/ 目录
4. 状态存放在 state/ 目录

## 常用命令

- `oc-collab status` - 查看状态
- `oc-collab phase-advance` - 推进阶段
- `oc-collab todo` - 管理任务
- `oc-collab signoff` - 签署确认
```

---

## 3. 验收标准

- [ ] 用户输入"你是 agent1"后，AI 自动读取 `.a` 文件
- [ ] `.a` 文件位于项目根目录
- [ ] Agent 1 和 Agent 2 使用同一个 `.a` 文件（角色信息相同）
- [ ] 用户无需记住文件名，只需记住"你是 agent1"这句话

## 4. 实现方式
