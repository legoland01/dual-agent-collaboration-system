## 三、版本规划

### 3.1 MVP范围

根据consultant确认，MVP必须包含：

| 功能 | 说明 |
|------|------|
| 入口 | 多模态输入统一入口 |
| 自动归属 | 客户识别 + 项目匹配 + 自动路由 |
| oc-collab整合 | 通过Git写入需求到oc-collab项目 |

**三者缺一不可，必须形成完整闭环。**

### 3.2 版本号

PM-Agent使用独立版本号，不与oc-collab共享。
