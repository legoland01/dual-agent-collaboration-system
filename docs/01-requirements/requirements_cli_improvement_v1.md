## 版本信息

- **变更类型**: 新功能

## 1. 变更概述

### 1.1 背景
当前双Agent协作框架CLI需要用户手动切换Agent、监控状态、执行操作，无法实现零干预自动协作。用户期望启动命令后，CLI能够自动检测状态并执行当前阶段应该做的事情。

### 1.2 目标
实现零干预自动协作模式：
- 用户只需运行 `oc-collab auto`
- CLI自动检测当前状态
- CLI自动执行当前Agent应该做的操作
- CLI自动处理协作流程直到完成

### 1.3 范围
新增三个命令：
- `oc-collab auto` - 自动执行当前任务
- `oc-collab todo` - 显示待办事项
- `oc-collab work` - 智能工作流引导

## 3. 非功能需求

### 3.1 性能需求
- 状态检测 < 1秒
- 自动执行不超时（用户可中断）

### 3.2 可用性需求
- 清晰的状态提示
- 明确的操作反馈
- 错误时给出解决建议

### 3.3 兼容性需求
- 兼容现有命令
- 兼容现有状态文件
- 跨平台支持

## 7. 工作流程

### 7.1 auto 命令执行流程
```
1. 同步远程变更
2. 检测当前状态（阶段、签署状态）
3. 判断当前Agent角色
4. 根据角色执行操作：
   - Agent 1: 创建文档、签署、评审
   - Agent 2: 评审、修复、签署、测试
5. 自动Git提交推送
6. 检查是否完成：
   - 未完成: 回到步骤1
   - 已完成: 退出并报告结果
```

### 7.2 状态机增强
```
当前状态 → 应该做什么 → 执行什么命令

project_init → 初始化 → init
requirements_draft → 创建需求文档 → 提示用户
requirements_review → 评审需求 → review --new + signoff
requirements_approved → 进入设计阶段 → 提示用户
design_review → 评审设计 → review --new + signoff
development → 开发修复 → 修复 + 测试
testing → 测试验证 → signoff
completed → 无操作 → 退出
```
