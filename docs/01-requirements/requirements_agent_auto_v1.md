## 1. 概述

### 1.1 背景

当前 `oc-collab auto` 命令需要手动触发，无法实现真正的自动化协作。

### 1.2 目标

实现 Agent 自动执行功能：
1. **自动执行模式** - 后台守护进程自动执行 `oc-collab auto`
2. **强制执行选项** - `oc-collab auto --force` 跳过本地变更检查
3. **智能触发** - 根据项目状态自动决定是否需要执行

### 1.3 范围

| 功能 | 优先级 | 说明 |
|------|--------|------|
| --force 选项 | P0 | 强制执行，跳过本地变更检查 |
| 自动执行守护进程 | P1 | 后台定期执行 auto 命令 |
| 智能触发 | P2 | 根据状态自动决定是否执行 |

## 2. 功能需求

#### 2.1.1 描述

| 编号 | 标准 |

| AC-003 | 无 `--force` 时行为不变 |

#### 2.1.3 优先级

**P0** - 必须实现

## 3. 接口设计

### 3.1 auto 命令增强

```bash
oc-collab auto [OPTIONS]

Options:
  --max-iterations, -n  最大迭代次数（默认 10）
  --quiet, -q           静默模式
  --force, -f           强制执行，跳过本地变更检查（重要！）
```

**注意**：`--force` 选项用于守护进程场景，跳过本地变更检查。

### 3.2 守护进程脚本

```bash
# 启动（每30秒检查一次）
nohup python3 scripts/agent_auto_runner.py \
    --path /path/to/project \
    --interval 30 > /tmp/agent_auto.log 2>&1 &

# 停止
pkill -f agent_auto_runner.py

# 查看日志
tail -f /tmp/agent_auto.log
```

### 3.3 自动执行的行为

| 阶段 | 自动执行的内容 | 手动执行的内容 |
|------|--------------|--------------|
| testing | - 自动检查阶段推进条件<br>- 条件满足时自动推进阶段 | - 执行黑盒测试<br>- 修复测试发现的问题 |
| development | - 自动执行分配的任务<br>- 自动同步 Git | - 编写代码<br>- 实现功能 |
| deployment | - 自动检查阶段推进条件 | - 部署操作<br>- 版本发布 |

**关键点**：守护进程会定期执行 `oc-collab auto --force`，但只会自动处理状态推进和签署，无法自动修复代码或执行测试。
