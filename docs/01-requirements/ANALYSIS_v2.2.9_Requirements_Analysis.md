## 五、决策依据

### 5.1 为什么自动报Bug是最高优先级？

| 依据 | 说明 |
|------|------|
| 用户期望 | 用户明确要求"遇到问题首先报Bug" |
| 痛点 | Agent不自觉报告问题，手动报告依赖外部 |
| 价值 | 自动化后问题发现率提升90%+ |

### 5.2 为什么Agent Compliance纳入v2.2.9？

| 依据 | 说明 |
|------|------|
| 用户要求 | 强制执行Skill是长期改进方向 |
| 技术评估 | CLI准入检查改动小（~100行） |
| 试点价值 | 可收集数据验证合规机制有效性 |

### 5.3 为什么推迟的功能继续推迟？

| 依据 | 说明 |
|------|------|
| 资源限制 | 23h已接近上限 |
| 复杂度高 | 逆向验证、Agent识别等需要重构 |
| 依赖缺失 | 部署自动化需先定义deployment.yaml |
| 风险高 | Todo编号迁移风险高 |
