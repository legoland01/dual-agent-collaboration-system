## 用户背景说明（v2.2.5 规划原则）

### 用户核心观点：Agent间通信的重要性

> "Agent之间通信具备相当的重要性，因为一方面这能将工作模式拓展到多个真人（跨机器）合作，另一方面这个将大幅提升工作的效率（减少需要人工介入搬运的任务）。"

### 用户对优先级的理解

| 优先级 | 功能 | 理由 |
|--------|------|------|
| **最高** | Agent间实时通信 | 基础设施，支撑跨机器协作 |
| **高** | 状态同步 + Webhook | Agent间通信的核心能力 |
| **中** | 部署自动化、启动引导 | 工具改进，效率提升 |
| **基础** | 止血（P0问题） | 阻塞性问题必须先解决 |

### 用户的分期原则

1. **超标不是问题**：关键是一个版本不要牵涉太多模块
2. **逐版本引入**：超复杂功能分版本逐步引入，避免一次性引入造成巨大bug
3. **稳步推进**：每期聚焦一个主题，稳步完善

### 用户的规则要求

> "做完一期 → 重新需求分析 → 调整排期 → 做当期需求文档。不要跨期做需求文档。"

此规则确保：
- 每期交付物清晰
- 避免需求蔓延
- 保持节奏可控
