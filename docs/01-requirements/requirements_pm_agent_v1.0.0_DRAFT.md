## 2. 功能需求

### 2.1 F-001: 多模态输入 + 预处理

**来源**: RESEARCH_image_search_mcp.md + 卷宗系统dossierai

**描述**: 支持多种格式的客户材料输入，调用dossierai服务进行预处理

**验收标准**:
- [ ] 支持图片格式：PNG, JPG, JPEG, GIF, BMP, WebP
- [ ] 支持音频格式：MP3, WAV, M4A, OGG, FLAC, WebM
- [ ] 支持文档格式：PDF, DOCX, DOC, TXT, MD
- [ ] 支持数据格式：JSON, CSV, XLSX, LOG
- [ ] 调用dossierai API进行OCR（图片→文字）
- [ ] 调用dossierai API进行语音转文字
- [ ] 调用dossierai API进行文档解析
- [ ] 调用dossierai API进行意图识别（BUG vs 需求）
- [ ] 预处理结果显示在处理结果列表中
- [ ] 支持配置dossierai服务地址

**整合说明**:
- dossierai服务地址：`http://localhost:4312/api/v1`
- 调用API：`POST /document/parse` - 文档解析
- 调用API：`POST /intent/recognize` - 意图识别
- 预处理结果存储后进行后续处理

**工时**: 4h（整合dossierai，原OCR/转录开发时间减免）

## 3. 自动化流程

### 3.1 完整自动化流程

```
客户材料（任意形式）
    │
    ▼
┌─────────────────────┐
│  PM-Agent           │
│  ┌───────────────┐  │
│  │ 内容理解       │  │ ← F-002 统一输入处理
│  │ 客户识别      │  │ ← F-003 客户识别
│  │ 项目匹配      │  │ ← F-004 项目匹配
│  │ 问题分类      │  │ ← F-008 问题自动分类
│  └───────────────┘  │
└─────────────────────┘
    │
    ├─────────────────────┐
    │                     │
    ▼                     ▼
BUG报告              功能Proposal
    │                     │
    │ ← F-009           │ ← F-010
    ▼                     ▼
问题跟踪 ←──────→ 需求池
    │                     │
    │ BUG修复/功能上线   │
    │ ← F-011 动态反馈   │
    └─────────┬───────────┘
              ▼
        状态自动更新
              │
              ▼
        客户反馈汇总
```

### 3.2 各功能依赖关系

| 功能 | 触发条件 | 下游功能 |
|------|----------|----------|
| F-008 问题分类 | 内容理解完成后 | F-009/F-010 |
| F-009 生成BUG | 分类为BUG | F-011 |
| F-010 生成Proposal | 分类为需求 | F-011 |
| F-011 动态反馈 | oc-collab状态变化 | - |
