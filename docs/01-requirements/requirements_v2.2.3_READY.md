## 2. 功能需求

### 2.1 F-CONTEXT-001: .a 文件机制

**目标**: 用户只需记住一句话 "oc init"，无需记住项目路径。

**.a 文件格式**:
```yaml
# .oc-collab.a
project: MyProject
path: /path/to/MyProject
agent: 1  # 或 2
```

**CLI 命令**:

| 命令 | 说明 |
|------|------|
| `oc-collab init` | 检测 .oc-collab.a 存在则跳过，否则创建 |
| `oc-collab .a` | 显示当前 .a 文件内容 |

**验收标准**:
- [ ] `oc-collab init` 检测到 `.oc-collab.a` 存在则跳过初始化
- [ ] `oc-collab init` 未检测到 `.oc-collab.a` 则引导用户创建
- [ ] `.oc-collab.a` 文件格式包含: project, path, agent
- [ ] `oc-collab .a` 命令显示当前关联的项目信息

**工时**: 5h

---

### 2.2 F-TASK-001: 任务状态自动同步

**目标**: todowrite/todoedit 操作后自动同步到文件。

**CLI 命令**:

| 命令 | 说明 |
|------|------|
| `oc-collab todowrite` | 操作后自动同步到 state/todo.yaml |
| `oc-collab todoedit` | 操作后自动同步到 state/todo.yaml |

**验收标准**:
- [ ] todowrite 操作后自动同步到 state/todo.yaml
- [ ] todoedit 操作后自动同步到 state/todo.yaml
- [ ] 同步时有明确提示 "✓ 已同步"
- [ ] 同步失败时有错误提示

**工时**: 2h

---

### 2.3 F-UI-001: 状态增强显示

**目标**: status 命令显示待办任务摘要。

**CLI 命令**:

| 命令 | 说明 |
|------|------|
| `oc-collab status` | 显示项目状态 + 待办任务摘要 |

**当前问题**:
```
当前 status 只显示:
┌───────────┬──────────────┐
│ 当前阶段  │ requirements │
│ 当前Agent │ Agent agent1 │
│ 待办数量  │ 0            │
└───────────┴──────────────┘
```

**改进后**:
```
┌───────────┬──────────────┐
│ 当前阶段  │ requirements │
│ 当前Agent │ Agent agent1 │
│ 待办数量  │ 3            │
└───────────┴──────────────┘

待办任务 (Agent1):
  [ ] 1. 完成需求文档
  [ ] 2. 评审设计文档
  [ ] 3. 签署测试确认
```

**验收标准**:
- [ ] status 显示待办任务列表（最多 5 条）
- [ ] 根据当前 Agent 角色过滤任务
- [ ] 显示任务优先级
- [ ] 待办为空时显示 "暂无待办任务"

**工时**: 2h
