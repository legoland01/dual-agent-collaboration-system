## 二、解决方案：任务后自检机制

### 2.1 核心思路

每次Agent完成任务后，自动添加一个"自检TODO"，Agent回顾任务过程，发现问题则生成Bug报告。

### 2.2 工作流程

```
Agent完成任务
        │
        ▼
┌─────────────────────┐
│ 系统自动添加自检TODO │ ← 每次任务后自动触发
└─────────┬───────────┘
          │
          ▼
    Agent执行自检
        │
        ▼
┌─────────────────────┐
│ 自检问题清单        │
│                     │
│ 1. 我刚才做了什么？ │
│ 2. 过程中遇到什么问题？│
│ 3. 有没有遗漏的bug？ │
│ 4. 用户有没有提到我没发现的问题？│
└─────────┬───────────┘
          │
          ▼
    发现问题？
          │
    ┌────┴────┐
   是         否
    │          │
    ▼          ▼
生成Bug   完成自检
```

### 2.3 实现方式

#### 2.3.1 自动添加自检TODO

在 `todowrite` 中自动添加自检TODO：

```python
# 任务完成后，自动添加自检
def _add_self_review_todo(original_todo_id: str):
    review_content = f"""
    自检任务：回顾 {original_todo_id} 的执行过程
    
    请回答以下问题：
    1. 任务目标是什么？完成了吗？
    2. 过程中遇到了什么问题？
    3. 有没有发现新的bug？
    4. 用户有没有提到我没注意到的问题？
    
    如果发现问题，请生成 Bug报告。
    """
    sync_manager.add_todo(review_content, agent_id=current_agent_id)
```

#### 2.3.2 自检执行

Agent执行自检TODO时：

```
【自检TODO示例】
TODO: 自检刚才的任务执行过程

【自检步骤】
1. 回溯任务目标
2. 回顾执行步骤
3. 检查结果是否符合预期
4. 检查用户反馈是否有未响应的问题
5. 发现问题 → 生成 Bug报告
```

### 2.4 触发场景

| 触发点 | 触发条件 |
|--------|----------|
| 任务完成 | todoedit --status completed |
| 评审完成 | signoff --phase |
| 部署完成 | deploy --complete |
| 任意Agent完成任务 | 所有命令执行成功 |
