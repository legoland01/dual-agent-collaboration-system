# Proposal: 保密项目文档隔离需求

**日期**: 2026-02-19  
**角色**: Consultant  
**目标**: PM-Agent v1.2

---

## 一、背景

部分项目由于保密要求，文档只能留在内网，不能同步到公开Git仓库。需要：
1. 区分"普通项目"和"保密项目"
2. 保密项目跳过文档同步
3. 保密项目禁止自动同步（防止意外泄露）
4. 同步时自动检查是否泄露保密信息

---

## 二、需求分析

### 2.1 使用场景

```
场景：工作人员分布式办公
- 保密项目文档：通过加密文件离线传递
- oc-collab：运行在客户内网，文档留在本地
- Git同步：只同步代码/测试/Bug
```

### 2.2 同步范围对比

| 内容 | 普通项目 | 保密项目 |
|------|---------|---------|
| 代码 src/ | ✅ | ✅ |
| 测试 tests/ | ✅ | ✅ |
| Bug报告 docs/bugs/ | ✅ | ✅ |
| 需求文档 docs/01-requirements/ | ✅ | ❌ 不同步 |
| 设计文档 docs/02-design/ | ✅ | ❌ 不同步 |

---

## 三、需求设计

### F-027: 项目保密级别配置

**需求描述**：配置项目保密级别，用于控制文档同步范围

**详细说明**：
- 项目配置增加"保密级别"字段（普通/保密）
- 区分可同步内容vs仅本地内容

**验收标准**：
- [ ] 支持配置项目保密级别
- [ ] 保密项目标记可查询

---

### F-028: 差异化同步规则

**需求描述**：根据项目保密级别，决定同步内容范围

**详细说明**：
- 普通项目：全量同步（代码+文档）
- 保密项目：仅同步代码/测试/Bug，跳过文档目录

**验收标准**：
- [ ] 保密项目同步时跳过docs/目录
- [ ] 保密项目文档不推送到远程仓库

---

### F-029: 保密项目自动同步控制

**需求描述**：当存在活跃的保密项目时，禁止自动同步

**详细说明**：
- 检测当前是否有活跃的保密项目
- 如有，禁用自动同步功能
- 手动同步时提示确认

**验收标准**：
- [ ] 检测保密项目活跃状态
- [ ] 活跃保密项目存在时禁用自动同步
- [ ] 手动同步前提示确认

---

### F-030: 保密信息同步检查

**需求描述**：保密项目每次Git同步时自动检查是否有保密信息被上传

**详细说明**：
- 同步前扫描即将推送的文件
- 检测关键词（如"保密"、"内部"、"confidential"）
- 发现敏感信息时阻止推送并告警

**检查规则**：
```yaml
# config/secret_check_rules.yaml
sensitive_keywords:
  - "保密"
  - "内部"
  - "confidential"
  - "secret"
  - "private"

exclude_patterns:
  - "*.md"  # 可配置是否检查文档
```

**验收标准**：
- [ ] 同步前自动扫描
- [ ] 发现敏感信息阻止推送
- [ ] 告警并提示处理方式

## 五、与oc-collab的协同

**结论：oc-collab无需改动**

所有功能在PM-Agent层实现：
- 项目保密级别配置：PM-Agent自己的项目配置
- 差异化同步：PM-Agent控制同步参数，跳过docs目录
- 保密信息检查：PM-Agent在推送前扫描

原因：PM-Agent作为同步入口，可以在发起同步前完成所有检查和过滤。
