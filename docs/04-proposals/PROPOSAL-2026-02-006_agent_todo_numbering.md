## 1. 问题背景

### 1.1 当前问题

```
TODO编号冲突导致数据损坏：

场景：
├── Agent1创建TODO-357
├── Agent2也创建TODO-357
└── 文件冲突 → YAML损坏 → todowrite失败

影响：
├── TODO数据损坏
├── todowrite工具调用失败
├── 协作流程断裂
```

### 1.2 问题频率

| 时间 | 冲突次数 | 影响 |
|------|----------|------|
| v2.2.9开发期间 | 2次 | YAML损坏2次 |
| v2.2.10开发期间 | 1次 | todowrite失败 |

### 1.3 根本原因

**当前机制缺陷**：

```
├── Agent1可以创建TODO
├── Agent2也可以创建TODO
└── 共用同一编号 → 冲突 → 数据损坏
```

---

## 2. 解决方案

### 2.1 核心思路

**每个Agent维护独立的TODO编号**：

```
Agent1的TODO：TODO-1-001, TODO-1-002, TODO-1-003...
Agent2的TODO：TODO-2-001, TODO-2-002, TODO-2-003...

同时创建也不会冲突！
```

### 2.2 编号格式

```
格式：TODO-{agent_id}-{sequence}

示例：
├── Agent1：TODO-1-001, TODO-1-002, ...
├── Agent2：TODO-2-001, TODO-2-002, ...
└── 独立计数器，永不冲突
```

### 2.3 实现方案

#### 2.3.1 State文件分离

```
state/
├── agent_adhoc_todos_1.yaml  # Agent1的TODO
└── agent_adhoc_todos_2.yaml  # Agent2的TODO
```

#### 2.3.2 统一视图

```python
# 合并两个文件，提供统一视图
def get_all_todos():
    todos1 = load("agent_adhoc_todos_1.yaml")
    todos2 = load("agent_adhoc_todos_2.yaml")
    return merge(todos1, todos2)
```

## 9. 专题分析引用

**文档**: `docs/00-memos/ANALYSIS_20260214_todo_yaml_relationship.md`

### 9.1 TODO创建与YAML错误的因果关系

```
Agent1创建TODO-357
    ↓
Agent2不知道357已存在，创建同样的TODO-357
    ↓
编号冲突 → YAML文件损坏
    ↓
todowrite工具解析失败 (BUG-003)
```

### 9.2 技术根因

| 问题 | 代码位置 | 缺陷 |
|------|----------|------|
| **编号无隔离** | `todo_sync_manager.py:178-187` | 所有Agent共用同一计数器 |
| **无分布式锁** | `sync_with_rollback` | 仅本地回滚，无并发控制 |
| **YAML结构冗余** | `save_todos()` | `total:`字段非标准 |

### 9.3 立即可行修复（与本Proposal并行）

| 优先级 | 行动 | 效果 |
|--------|------|------|
| **P0** | 删除`total:`冗余字段 | 消除LSP警告 |
| **P0** | 添加ID唯一性预检查 | 防止重复写入 |
