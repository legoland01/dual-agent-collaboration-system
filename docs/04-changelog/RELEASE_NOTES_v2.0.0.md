# Release Notes v2.0.0

**版本**: 2.0.0  
**发布日期**: 2026-02-01

## 版本说明

本版本发布 oc-collab Agent 守护进程功能 (FEATURE-009)，实现双 Agent 自动协作流程的后台运行能力。

---

## 功能变更

### 新增功能

| 功能 | 描述 | 状态 |
|------|------|------|
| AgentDaemon | 后台模式运行支持 | ✅ |
| ProcessSupervisor | 进程监管与自动重启 | ✅ |
| Git 超时控制 | Git 操作超时保护 | ✅ |
| CLI 命令 | --daemon, --supervise, --status, --stop | ✅ |

### CLI 命令

```bash
# 后台模式
oc-collab agent --daemon

# 进程监管模式
oc-collab agent --supervise

# 查看状态
oc-collab agent --status

# 停止服务
oc-collab agent --stop
```
