# Bug Report: TODO编号与实际Agent身份不一致

## Bug ID
BUG-20260218-001

## 严重程度
P1

## 问题描述
创建TODO时，编号生成使用的sender（发送者）可能与当前Agent身份不一致。

当前问题：
1. `project_state.yaml` 中 `current_agent` 决定当前身份
2. 但CLI命令可能通过 `OC_AGENT_ID` 环境变量覆盖
3. 或者 `ContextManager` 读取的上下文与实际执行环境不一致

## 复现步骤
1. 设置 `OC_AGENT_ID=1` 运行命令
2. 但 `project_state.yaml` 中 `current_agent: agent2`
3. 创建TODO时编号可能错误

## 期望行为
- TODO编号应该与实际执行命令的Agent身份一致
- sender应该是当前登录的Agent（从project_state.yaml读取）

## 当前状态
待修复
