# BUG-20260214-006: Agent无法自动感知下一步行动

**发现日期**: 2026-02-14  
**发现人**: Agent 1  
**严重度**: P1  
**状态**: OPEN

---

## 问题描述

Agent1经常遗漏步骤，无法自动感知下一步该做什么。

## 问题示例

| 场景 | 应该做 | 实际做 |
|------|--------|--------|
| 验收后 | 创建部署TODO | 直接问用户 |
| 创建需求后 | 创建设计TODO | 遗漏 |
| 评审后 | 创建开发TODO | 遗漏 |
| 遇到问题 | 报BUG | 忘记 |

## 期望行为

```
Agent收到任务
    │
    └── 自动分析当前状态
            │
            ├── 识别已完成的步骤
            ├── 识别下一步
            └── 建议/执行下一步
```

## 实际行为

```
Agent收到任务
    │
    └── 不知道下一步是什么 ❌
            │
            └── 需要用户提示
                    │
                    └── 或直接跳过
```

## 影响范围

- Agent1所有协作场景
- 流程断裂
- 依赖人工记忆
- 频繁遗漏步骤

## 根因分析

**没有自动状态机**

| 组件 | 实现状态 |
|------|----------|
| 状态记录 | ✅ 有project_state.yaml |
| 状态检查 | ❌ 无自动检查 |
| 下一步建议 | ❌ 无 |

## 临时解决方案

- 人工记忆流程
- 用户提示下一步
- 频繁创建BUG记录遗漏

## 根本解决方案

```
v2.2.10 或后续版本实现：
└── 协作状态机
        │
        ├── 状态检查器
        │       │
        │       └── 自动检查当前状态
        │
        ├── 下一步建议
        │       │
        │       └── 基于状态生成建议
        │
        └── 自动创建TODO
                │
                └── 识别下一步 → 自动创建
```
