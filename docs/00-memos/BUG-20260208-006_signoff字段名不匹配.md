# Bug 报告：signoff.py字段名不匹配（BUG-20260208-004残留）

**严重程度**: P0

## Bug描述

### 表现形式

| 场景 | 问题 |
|------|------|
| 执行 `oc-collab signoff test` | 报错"当前阶段状态不允许签署" |
| 调试 signoff._get_stage_data('test', state) | 返回空 {} |
| v2.2.4.testing | 有数据但未被识别 |

### 根本原因

| 组件 | 字段名 |
|------|--------|
| signoff.py (STAGE_CONFIG) | `test` |
| v2.2.4 project_state.yaml | `testing` |

### 问题代码

```python
# signoff.py _get_stage_data()
version_data = state.get(latest_version, {})
stage_data = version_data.get(status_field, {})  # status_field = "test"

# 但 v2.2.4 使用的是 "testing"
# 所以 version_data.get("test") = None
```

### 影响范围

| 影响 | 严重程度 |
|------|----------|
| 无法签署测试验收 | P0 - 阻塞流程 |
| v2.2.x验收流程失效 | P0 |

---

## 解决方案

### 方案A: 修改signoff.py同时检查'test'和'testing'

```python
# 在_get_stage_data()中
if stage == "test":
    stage_data = version_data.get("testing", version_data.get("test", {}))
else:
    stage_data = version_data.get(status_field, {})
```

### 方案B: 修改project_state.yaml字段名

将 `v2.2.4.testing` 改为 `v2.2.4.test`

---

## 临时解决方案

```bash
# 在 project_state.yaml 中同时添加 test 字段
python3 -c "
import yaml
with open('state/project_state.yaml') as f:
    state = yaml.safe_load(f)

# 添加顶层 test 字段
state['test'] = state['v2.2.4']['testing']

with open('state/project_state.yaml', 'w') as f:
    yaml.dump(state, f, allow_unicode=True)
"
```
