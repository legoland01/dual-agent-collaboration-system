### 具体问题

#### 1. init 命令参数不匹配

**当前实现**:
```bash
oc-collab init PROJECT_NAME [--type python|typescript|mixed|auto] [--force]
```

**设计要求**:
```bash
oc-collab init [--name PROJECT_NAME] [--path PATH] [--agent 1|2]
```

#### 2. .a 命令未实现

**设计**: 显示项目信息（.oc-collab.yaml 内容）
**当前**: 命令不存在

#### 3. todowrite 命令未实现

**设计**: 创建待办任务
```bash
oc-collab todowrite --content "任务描述" [--priority high|medium|low] [--agent 1|2]
```
**当前**: 命令不存在

#### 4. todoedit 命令未实现

**设计**: 更新待办任务
```bash
oc-collab todoedit TODO-001 [--status pending|in_progress|completed] [--priority high|medium|low]
```
**当前**: 命令不存在

#### 5. status 命令未增强

**设计**: 显示待办摘要（当前 Agent 的待办列表）
**当前**: 仅显示基本信息
