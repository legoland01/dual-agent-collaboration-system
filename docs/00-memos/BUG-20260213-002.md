## 1. Bug描述

在完成工作后，未参考Skill进行自检，违背了AGENTS.md对Agent的要求。

### 表现

| 场景 | 应该做 | 实际做 |
|------|--------|--------|
| 需求评审后 | 参考oc_collab_requirements_review_guide自检 | ❌ 直接创建下一步TODO |
| 概要设计评审后 | 参考oc_collab_outline_design_guide自检 | ❌ 直接创建下一步TODO |
| 详细设计创建后 | 参考oc_collab_detailed_design_guide自检 | ❌ 直接进入开发阶段 |
| 任何评审完成后 | 按Skill规定的签署流程更新文档 | ❌ 漏做 |

### 违反的规定

**AGENTS.md**:
```
## Skill 查询规则 ⭐

**永远不要直接问用户，先查Skill**

1. **遇到问题时的处理顺序**：
   - Step 1: 查阅 `skills/` 目录下的相关Skill
   - Step 2: 使用 `oc-collab skill search --keywords <关键词>` 搜索
   - Step 3: 如果Skill有SOP四要素，按照步骤执行
   - Step 4: 如果Skill找不到或觉得困惑，再问用户
```

**各阶段Skill规定的自检项**:

| 阶段 | Skill | 应做自检项 |
|------|-------|------------|
| 需求评审 | oc_collab_requirements_review_guide | 更新文档状态为APPROVED |
| 概要设计评审 | oc_collab_outline_design_guide | 更新文档状态为APPROVED |
| 详细设计创建 | oc_collab_detailed_design_guide | 设置状态为READY，待Agent1评审 |

---

## 3. Bug根因分析

### 直接原因

完成工作后直接进入下一步，忘记了参考Skill。

### 深层原因

1. **流程意识不足**: 过于关注任务完成，忽视了自检环节
2. **缺少提醒机制**: 没有强制要求完成工作后必须参考Skill
3. **习惯养成不足**: 没有建立"完成即自检"的习惯

---

## 4. 修复建议

### 方案A: 强制自检checklist (推荐)

在TODO完成描述中增加自检checklist：

```yaml
- id: TODO-xxx
  content: xxx
  self_check:
    - "参考Skill自检：是否完成X"
    - "参考Skill自检：是否完成Y"
  status: pending
```

### 方案B: 模板中增加自检项

在TODO模板中增加"自检完成"字段：

```yaml
self_check_done: false
self_check_items:
  - "参考Skill: xxx"
```

### 方案C: 流程强制检查

创建pre-commit hook或CI检查：
- 检查文档状态是否正确更新
- 检查是否完成必要的签署流程
