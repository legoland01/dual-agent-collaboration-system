# Bug 报告：signoff.py不支持v2.2.x版本化结构

**Bug ID**: BUG-20260208-004
**严重程度**: P0
**状态**: 待修复
**发现人**: Agent 1

## Bug描述

### 表现形式

| 场景 | 问题 |
|------|------|
| 执行 `oc-collab signoff test` | 报错"当前阶段状态不允许签署" |
| 调试signoff._get_stage_data('test', state) | 返回空字典 {} |
| 顶层test字段 | 空 {} |
| v2.2.4.testing | 有数据但未被识别 |

### 重现场景

```python
from src.core.signoff import SignoffEngine
from src.core.state_manager import StateManager

state_manager = StateManager('.')
engine = SignoffEngine(state_manager, Mock())

state = state_manager.load_state()
stage_data = engine._get_stage_data('test', state)

# 问题：
# stage_data = {}  # 空字典
# 但 v2.2.4.testing = {'status': 'in_progress', ...}
```

### 影响范围

| 影响 | 严重程度 |
|------|----------|
| 无法签署测试验收 | P0 - 阻塞流程 |
| v2.2.x验收流程失效 | P0 |

## 问题分析

### 根因分析

| 问题 | 原因 | 层级 |
|------|------|------|
| signoff.py 只检查顶层字段 | _get_stage_data() 使用 state.get("test", {}) | 代码 |
| v2.2.x 使用版本化结构 | testing数据在 v2.2.x.testing | 架构 |

### 相关代码

```python
# src/core/signoff.py 第73-90行
def _get_stage_data(self, stage: str, state: dict) -> dict:
    config = self.STAGE_CONFIG.get(stage, {})
    status_field = config.get("status_field", stage)
    stage_data = state.get(status_field, {})  # 这里只检查顶层
    
    # 对于test阶段，status_field = "test"
    # 所以只检查 state.get("test", {})
    # 忽略了 v2.2.x.testing
```

### 解决方案

| 方案 | 说明 | 工时 |
|------|------|------|
| 方案A | 修改_get_stage_data()识别v2.2.x结构 | 1h |
| 方案B | 在project_state.yaml顶层添加test字段 | 0.5h |
| 方案C | 让signoff.py支持动态版本结构 | 2h |

**推荐**: 方案A 或 方案B
