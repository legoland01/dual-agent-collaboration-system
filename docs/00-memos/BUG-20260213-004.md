# BUG-20260213-004: CLI Commands Not Implemented

**Severity**: P1
**Status**: acknowledged
**Date**: 2026-02-13
**Reporter**: Agent 1

---

## Description

The CLI commands for `oc-collab rules init` and `oc-collab rules status` are NOT implemented, even though they are specified in the v2.2.8 detailed design document (DETAIL_v2.2.8.md).

## Expected Behavior

According to DETAIL_v2.2.8.md Section 6.1, the following commands should be available:

| Command | Parameters | Return Value | Description |
|---------|------------|--------------|-------------|
| `oc-collab rules init` | [--force] | 0=成功, 1=失败 | Initialize framework rules |
| `oc-collab rules status` | 无 | 0=成功 | Check rules initialization status |

## Actual Behavior

```bash
$ oc-collab rules init
Error: No such command 'rules'.

$ oc-collab rules status
Error: No such command 'rules'.
```

## Impact

- The `RulesInitializer` module (src/core/rules_initializer.py) is implemented and unit tested
- However, it cannot be accessed via CLI because `src/cli/rules_commands.py` is missing
- This blocks the E2E testing and release of v2.2.8

## Root Cause

According to DETAIL_v2.2.8.md Section 1.2, the file `src/cli/rules_commands.py` was scheduled for 1 hour of development, but was NOT created.

## Evidence

1. **Unit Tests**: 31/31 passed for core modules (EventDispatcher, StateNotifier, HMACValidator, RulesInitializer)
2. **CLI Commands**: Not available in `oc-collab --help`
3. **File Missing**: `src/cli/rules_commands.py` does not exist

## Recommendation

**Agent2 needs to implement `src/cli/rules_commands.py`**:

```python
# src/cli/rules_commands.py

import click
from src.core.rules_initializer import RulesInitializer

@click.group()
def rules():
    """Rules management commands"""
    pass

@rules.command()
@click.option('--force', is_flag=True, help='Force overwrite existing files')
def init(force):
    """Initialize framework rules"""
    initializer = RulesInitializer()
    result = initializer.init(force=force)
    click.echo(f"Success: {len(result.created_files)} files created")
    if result.skipped_files:
        click.echo(f"Skipped: {len(result.skipped_files)} files")

@rules.command()
def status():
    """Check rules initialization status"""
    initializer = RulesInitializer()
    status = initializer.check_status()
    click.echo(f"Initialized: {len(status['initialized'])}")
    click.echo(f"Missing: {len(status['missing'])}")
```
