# Bug报告: Agent2无法自动发现和创建TODO

**Bug ID**: BUG-20260215-016
**严重程度**: P0
**状态**: Open
**发现时间**: 2026-02-15
**发现者**: Agent 1

---

## 问题描述

当前Agent2无法自动发现需要执行的任务并创建TODO。系统缺少自动任务发现机制。

## 问题分析

当前状态：
1. Agent1可以手动创建TODO并分配给Agent2
2. Agent2无法自动发现需要执行的任务
3. 缺少任务自动发现和TODO创建机制

## 根因

系统缺乏以下功能：
1. 没有自动检测未处理需求→创建TODO的机制
2. 没有自动检测设计文档→创建开发TODO的机制
3. 没有自动检测测试失败→创建修复TODO的机制

## 期望行为

Agent2应该能够：
1. 自动扫描项目状态，发现待处理任务
2. 根据项目阶段自动创建相应TODO
3. 或者提供命令让Agent2主动发现任务

## 修复建议

方案1：增强Agent2启动检查
```python
# oc-collab switch 2 时自动检查
def auto_discover_tasks():
    # 检查未签署的需求 → 创建评审TODO
    # 检查未实现的设计 → 创建开发TODO
    # 检查失败的测试 → 创建修复TODO
```

方案2：新增命令
```bash
oc-collab agent2 discover  # 发现需要处理的任务
```
