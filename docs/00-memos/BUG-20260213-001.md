2. **立即使用 edit 工具写入文件**

**示例**：
```python

# 2. edit工具（真正写入）

  filePath="state/agent_adhoc_todos.yaml",
  oldString="- id: TODO-290\n  content: ...",
  newString="- id: TODO-290\n  content: ...\n- id: TODO-291\n  content: ..."

# 3. grep验证
```

## 2. 问题分析

### CLI命令正常工作

CLI命令 `oc-collab todowrite` 使用 `TodoSyncManager.sync_with_rollback()` 实现：

```python
def sync_with_rollback(self, operation: Callable) -> bool:
    try:
        self.create_backup()
        operation()  # 执行 add_todo -> save_todos
        return True
    except Exception as e:
        if self.rollback():
            pass
        return False
```

**结论**: CLI命令逻辑正确，可以正常工作。

### todowrite工具异常

`todowrite` 工具可能：
1. 调用了不同的实现
2. 在工具调用层拦截了结果
3. 返回了模拟成功但未实际执行
