## 一、第一优先级：oc-collab集成

### 1.1 Agent管理

| 功能 | 说明 | 状态 |
|------|------|------|
| Agent ID分配 | 分配agent1、agent2等ID | ⏳ |
| TODO寻址 | Agent在TODO系统中的标识 | ⏳ |
| 启动/关闭 | 固定Agent的启动停止 | ⏳ |

### 1.2 Prompt模板

| 功能 | 说明 | 状态 |
|------|------|------|
| 启动模板管理 | Agent启动时的OpenCode prompt | ⏳ |
| agent.md生成 | 项目特有的agent.md模板 | ⏳ |

### 1.3 问题同步

| 功能 | 说明 | 状态 |
|------|------|------|
| 自动推送问题 | PM-Agent → oc-collab TODO | ⏳ |
| 状态同步 | 问题处理状态双向同步 | ⏳ |

## 二、第二优先级：文件处理

### 2.1 导入文件处理

| 功能 | 说明 | 状态 |
|------|------|------|
| OCR/转写后处理 | 识别项目、创建纪要 | ⏳ |
| 文件整合 | 多文件合并统一格式 | ⏳ |

### 2.2 文件同步

| 功能 | 说明 | 状态 |
|------|------|------|
| 自动同步 | 开发代码/文档（需求→代码→测试报告） | ⏳ |
| 手动同步 | 用户原始文档，多选/全选/全不选 | ⏳ |

### 2.3 同步规则

```
文件类型                  同步方式    说明
─────────────────────────────────────────────
开发代码                  自动        代码、需求、测试报告
PM-Agent系统文档          自动        自动推送到仓库
用户原始文档               手动        用户选择后同步
商务/密级文件             不同步      本地保存
```
| 仓库更新 | 自动同步仓库 | ⏳ |

### 2.3 自动功能

| 功能 | 说明 | 状态 |
|------|------|------|
| 自动创问题 | 根据材料内容创建问题 | ⏳ |
| 目录同步 | 同步项目文件目录结构 | ⏳ |

## 三、技术实现

### 3.1 oc-collab集成

```python
# 调用oc-collab CLI
subprocess.run(["oc-collab", "todo", "create", ...])
subprocess.run(["oc-collab", "agent", "start", ...])
```

### 3.2 文件存储

```
项目目录/
├── materials/        # 上传的材料
├── meetings/        # 会议纪要
├──整合文件/        # 整合后的文件
└── .gitkeep        # 占位
```
