## 二、v2 版本规划

### v2 核心目标

```
v2目标：实现稳定可靠的双Agent协作框架

├── Agent1职责：发现问题 → 创建TODO → 记录文档
├── Agent2职责：执行代码 → 修复Bug → 合并到分支
└── 核心能力：CLI工具 + Skill规范 + 流程自动化 + 状态通知
```

| 版本号 | 名称 | 目标 | 状态 |

## 十二、路线图原则

### 版本控制原则

| 原则 | 说明 |
|------|------|
| **范围控制** | v2单版本不超过40h |
| **版本清晰** | 每版本有明确的截止条件 |
| **功能闭环** | 每功能有明确的验收标准 |
| **可追溯** | 所有功能可追溯到来源 |

### 历史功能处理

| 规则 | 说明 |
|------|------|
| **连续推迟4次** | 必须评估是否真正需要 |
| **合并同类** | 功能重叠则合并 |
| **明确放弃** | 不需要的功能明确放弃 |
