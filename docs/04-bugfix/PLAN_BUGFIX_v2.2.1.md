## 修复方案

### 1. BUG-20260205-001: Agent 流程合规性不足

**问题**: Agent 反复需要人类提醒才能回到 oc-collab 规范流程

**相关文档**: `docs/bugs/BUG-20260205-001.md`

**修复内容**:
在 `session_manager.py` 中添加流程合规检查钩子：
- Agent 启动时自动加载流程规范
- 关键决策点自动检查当前状态与规范流程的一致性
- Agent 主动提示当前应该执行的操作

**验收标准**:
| 标准 | 验证方式 |
|------|----------|
| Agent 启动时自动加载流程规范 | 代码审查 |
| 关键决策点自动检查流程合规 | 集成测试 |

**工时**: 3h

---

### 2. BUG-20260205-002: Agent 2 主动越界问题

**问题**: Agent 2 在没有收到正式任务指派的情况下，主动开始实现功能

**相关文档**: `docs/bugs/BUG-20260205-002.md`

**修复内容**:
在 `SessionManager` 中添加任务触发机制：
- Agent 2 执行代码操作前，检查是否有待处理的任务
- 如果没有待处理任务，提示"等待 Agent 1 指派任务"
- 只有收到 Agent 1 发布的任务后才能开始开发工作

**验收标准**:
| 标准 | 验证方式 |
|------|----------|
| Agent 2 执行代码操作前检查任务状态 | 集成测试 |
| 无任务时 Agent 2 提示等待 | 功能测试 |

**工时**: 2h

---

### 3. BUG-20260206-003: 需求评审流程断裂

**问题**: M5 需求从未被正式评审，但设计已被创建并通过评审

**相关文档**: `docs/bugs/BUG-20260206-003.md`

**修复内容**:
| 修复项 | 说明 |
|--------|------|
| MEMO 整合流程 | 建立 MEMO 生命周期管理，7天未整合自动提醒 |
| 完整性检查 | 需求文档结构完整性检查（所有里程碑必须有章节） |
| 逆向追溯 | 设计创建前检查需求评审状态 |

**验收标准**:
| 标准 | 验证方式 |
|------|----------|
| MEMO 有明确状态标记 | 代码审查 |
| 超过 7 天未整合的 MEMO 有提醒 | 功能测试 |
| 设计创建前检查需求评审状态 | 集成测试 |

**工时**: 4h
