## 业界标准测试方法

### 为什么移除字符串匹配测试？

| 问题 | 说明 |
|------|------|
| 无文档依据 | 没有任何官方文档规定 CLI 的确切输出文本 |
| 脆弱测试 | 输出文本变化会导致测试失败，但功能正常 |
| 维护成本 | 需要持续更新预期值，无实际价值 |

### 业界标准做法

1. **冒烟测试**：只检查退出码 (0 = 成功)
2. **功能测试**：验证实际行为（权限拒绝、状态变化）
3. **Output 测试**：仅当有 Golden File 或正式规范时才做
